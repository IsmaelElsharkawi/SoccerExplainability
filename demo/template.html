Grounding scores for this clip

Spatial scores average the annotated frames of the clip; temporal scores compare each model's per-frame relevance with the frames that carry a cue of the selected tier. Values in %. Best model per column in bold. The paper reports means over all 1,000 clips; single clips vary widely.

What you see

Each clip is sampled at one frame per second (30 frames). The input panel shows the annotated cues. Each model panel shows its attribution map for the selected frame over a dimmed copy of the frame, with the same cues on top. Relevancy is shown on the jet scale, and low values are left transparent.

Attribution method

MatchVision and SoccerMaster use Chefer-T, which propagates relevance through both spatial and temporal attention. SigLIP has no temporal attention and uses standard Chefer per frame. Maps are 14×14 (MatchVision, SigLIP) or 32×32 (SoccerMaster) patch grids, upsampled and smoothed for display only.

Controls

Click a panel to enlarge it. ← → step through frames, Space plays, 1–4 enlarge a panel, Esc returns to the grid. Click the chart or the film strip to jump to a frame. The link updates to the selected clip so it can be shared.
