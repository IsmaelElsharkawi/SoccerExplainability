Provenance and integrity checks

Source: SoccerExplainability-output-20260727T084020Z-1-001.zip, pulled from the Drive output root. All 10 runs (3 SigLIP, 3 MatchVision, 4 SoccerMaster) report git_commit: ee51a38 in their run_info.txt, and each carries the full 200/200 saliency sidecars. Before computing anything: (1) repeat runs within each model were content-checksummed and are byte-identical, matching the “deterministic pipeline” finding from the previous page — so one representative run per model was used, not an average; (2) the P+S+C headline reproduces the previously-verified values exactly — SigLIP 22.71 / 27.56 / 2.98 / 28.67, MatchVision 39.11 / 44.20 / 7.47 / 14.99, SoccerMaster 37.05 / 50.47 / 3.62 / 14.90 (Energy / Pointing / S-IoU / T-IoU) — confirming this zip is the same lineage, not a divergent or broken-weights run.

SigLIP prediction distribution: worth flagging, not disqualifying

Following the previous page's open item (“checking the prediction distribution is how a broken-weights run was caught previously”): SigLIP's prediction_text collapses to a single class, foul lead to penalty, on 168/200 clips (5 distinct predictions total, 7.5% classification accuracy). MatchVision and SoccerMaster show healthy spread — 16 distinct predictions each, 62.5% and 66.0% accuracy. This is not a new problem introduced by this zip: the grounding metrics above reproduce the already-cited values exactly, so it is the same checkpoint the earlier numbers came from. But it means SigLIP's Energy/Pointing/IoU scores describe how well its saliency locates cues for a mostly-wrong predicted label, not for the true event class — worth stating explicitly if these numbers go in the rebuttal.

S-IoU degrades faster than T-IoU did: every model falls by roughly half just from 0.50→0.60, versus the much shallower T-IoU curve in Table 2. Integrating this curve trapezoidally reproduces Table 4's S-AUC to within 1–4% relative — the residual gap is a single frame-inclusion rule: S-AUC drops individual frames whose rasterized 14×14 ROI mask is degenerate (all-foreground or all-background) before integrating per-frame, while this table averages IoU across frames first and integrates that average, so a frame excluded from one is not necessarily excluded from the other.
