Provenance and integrity checks

Source: SoccerExplainability-output-20260727T084020Z-1-001.zip, pulled from the Drive output root. All 10 runs (3 SigLIP, 3 MatchVision, 4 SoccerMaster) report git_commit: ee51a38 in their run_info.txt, and each carries the full 200/200 saliency sidecars. Repeat runs within a model were checksummed and are byte-identical, so the pipeline is deterministic and one representative run per model is used rather than an average. Runs from different models are not identical to each other, which rules out the copied-bundle mix-up seen previously.

SigLIP prediction distribution: worth flagging, not disqualifying

SigLIP guesses the same answer, foul lead to penalty, on 168 of the 200 clips — only 5 different answers in total, and it gets 7.5% right. MatchVision and SoccerMaster spread out properly: 16 different answers each, 62.5% and 66.0% right. This is the checkpoint’s own behaviour, not a bad download. It does mean SigLIP’s scores below describe how well it points at cues for an answer that is usually wrong, rather than for the event that actually happened — worth saying out loud if these numbers go into the rebuttal.

Second bundle · different runs

Native-grid maps, ten model/method pairs

Everything from here down comes from a different set of runs to Tables 1–5 and is not a like-for-like extension of them. Two differences matter. These runs explain the true event class, whereas Tables 1–5 explain whatever the model actually guessed. And they come from a different build of the code (48a31962, not ee51a38), with maps that differ from the earlier bundle on all 200 clips. Same 200 clips and the same annotation file throughout, so the ground truth is unchanged.

Provenance and integrity checks

Source: output_native_grid_maps_sait.zip. Ten map sets, 200 clips each, and all ten are distinct from one another by content checksum — no copied directories. The bundled annotations-coco.json is byte-identical to the repository's. The evaluator used here reproduces every published SigLIP figure in Table 1 exactly when pointed at the old bundle, so the new numbers come from a checked pipeline rather than a fresh one.

Four caveats that travel with these numbers

1. Nothing was precomputed. The bundle's README marks its cached score fields as stale output from an older evaluator, so every figure below was recomputed from the raw maps. 2. Four of the ten sets ship no provenance manifest — SigLIP, both MatchVision sets, and SoccerMaster Chefer-T. 3. SoccerMaster Chefer is not an independent run (⚠ in the table): its manifest says it was reconstructed from the Chefer-T maps by dividing out the per-frame temporal weight, so the two SoccerMaster rows are not independent evidence. 4. One run each, so there is no repeat-run agreement here of the kind Table 1 reports.

Two things to read carefully. The four spatial scores — Energy, Pointing, S-IoU, S-AUC — come out the same for Chefer and Chefer-T on every model, and that is arithmetic rather than coincidence: all four are computed relative to each frame’s own maximum, and Chefer-T differs from Chefer only by a per-frame multiplier, which cancels. Only the four temporal scores can tell the two methods apart, and there the gap is large for PE-AV (T-IoU 23.53 against 13.79) and VideoPrism (26.30 against 19.61) but negligible for SoccerMaster. Separately, grid size is not neutral: S-IoU and Pointing depend on how finely a bounding box can be drawn on the model’s own grid, so part of any spatial gap between a 14×14 and a 32×32 model reflects resolution rather than grounding quality.
